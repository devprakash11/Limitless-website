# Limitless Design Frontend

Professional React frontend for **Limitless Design**, a creative design marketplace.

## Tech Stack

- React
- Vite
- React Router DOM
- Lucide React Icons
- CSS

## Pages

- `/` Home
- `/about` About
- `/contact` Contact / Commission Work
- `/services/logo-design`
- `/services/social-media-banner`
- `/services/photo-frame`
- `/services/poster-design`
- `/services/business-card-design`
- `/services/branding-materials`
- `/services/ui-design`
- `/services/creative-design`

## Run Project

```bash
npm install
npm run dev
```

Open:

```txt
http://localhost:5173/
```

## Build Project

```bash
npm run build
```

## Preview Production Build

```bash
npm run preview
```
